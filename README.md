
# Tip Calculator 💰

A simple tip calculator built using HTML, CSS, and JavaScript. It calculates the total bill amount based on the bill value and tip percentage entered by the user.

## Features

- Enter the bill amount.
- Enter the desired tip percentage.
- Calculate the tip and total bill amount.
- Display the calculated total instantly.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Enter the bill amount.
2. Enter the tip percentage.
3. Click the Calculate button.
4. View the total bill amount, including the tip.

## Calculation

Tip Amount = Bill Amount × Tip Percentage / 100

Total Bill = Bill Amount + Tip Amount
